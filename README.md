# Dienstplan

Offline-Web-App für Monatsdienstpläne einer Pflegestation (Früh-, Spät-, Nachtdienst) mit Automatik-Vorschlag und Regelprüfung.

- Läuft komplett im Browser, auch ohne Internet (nach dem ersten Öffnen).
- iPhone/iPad: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
- Alle Daten bleiben auf dem Gerät. Weitergabe nur über „Als Datei sichern / teilen“.
- Dieses Repository enthält keine Personal- oder Dienstplandaten.
